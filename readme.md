# Avicultura do Futuro - Plataforma Digital Agrotech

## 📝 Tema da Página
Esta aplicação web aborda a **Avicultura de Postura**, unindo de forma harmônica os conceitos tradicionais de produção no campo com as inovações tecnológicas de ponta (Inteligência Artificial, Automação Computadorizada e Internet das Coisas - IoT). O design foi planejado seguindo uma paleta visual sofisticada de cores preta, branca, marrom e amarela, conferindo uma atmosfera premium e altamente corporativa ao agronegócio moderno.

## 🎯 Objetivo da Página
O objetivo principal da página é instruir e conscientizar o público sobre a evolução dos diferentes sistemas de criação de aves poedeiras no Brasil (Convencional, Cage-free, Free-range, Caipira e Orgânico). O foco central reside em contrapor a eficiência e a produtividade com as crescentes exigências globais de bem-estar animal, nutrição de precisão e sanidade ambiental preventiva, demonstrando como a automação através de esteiras e monitoramento preditivo pode mitigar perdas no setor.

## 🚀 Instruções de Uso
1. **Instalação**: Extraia o conteúdo do arquivo compactado em um diretório local no seu computador.
2. **Visualização**: Dê um clique duplo ou abra o arquivo `index.html` em qualquer navegador web moderno de sua escolha.
3. **Exploração de Conteúdo (Accordion)**: Na seção de modelos produtivos, clique nos títulos das categorias para expandir e recolher os blocos detalhados de informações.
4. **Formulário de Inscrição**: Utilize o formulário posicionado de forma fixa e elegante à direita do layout para preencher os seus dados e simular uma inscrição no ecossistema agrotech.
5. **Ferramentas de Acessibilidade**: Utilize o menu fixo posicionado no lado esquerdo da tela para gerenciar:
   - Tamanho das fontes dinâmicas (botões `A+` e `A-`).
   - Alternância de contraste (Modo Claro / Modo Escuro via botão de eclipse).
   - Conversão de Texto em Voz Nativa (`🔊 Ouvir` e `🛑 Parar`) para leitura inclusiva do conteúdo principal usando a Web Speech API.
6. **Inserção de Imagens Reais**: Para carregar as suas próprias mídias de alta resolução, basta salvar as fotos desejadas na mesma pasta com os nomes correspondentes (`Foto1.png`, `Foto2.png`, `Foto3.png`, `Foto4.png` e `Foto5.png`). As molduras já estão configuradas com cantos arredondados, sombras suaves e efeito dinâmico de hover.
